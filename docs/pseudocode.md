# Value Iteration Algorithm## Textbook Version (Figure 9.16)Initialize V₀(s) arbitrarilyRepeat: For each state s: Vₖ(s) = maxₐ [ R(s,a) + γ Σ P(s'|s,a) Vₖ₋₁(s') ]Until convergenceThen: π(s) = argmaxₐ [ R(s,a) + γ Σ P(s'|s,a) V(s') ]## My ImplementationInitialize V(s) = 0Initialize policy(s) = NoneRepeat: For each state s: Skip terminal states For each action a: Compute expected value: Σ P(s'|s,a) * (R(s,a,s') + γ V(s')) Choose best action Update V(s) Update policy(s)Until change < θ## Differences from Textbook1. I use **in-place updates** (asynchronous), instead of storing Vₖ and Vₖ₋₁ 2. Rewards depend on (s, a, s') instead of only (s, a) 3. Policy is computed during iteration instead of after These changes improve efficiency and match the grid world structure.
